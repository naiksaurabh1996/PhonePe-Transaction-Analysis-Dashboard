# PhonePe-Transaction-Analysis-Dashboard
Developed an interactive Power BI dashboard to analyze PhonePe transaction data across different financial services including Insurance, Loans, Money Transfers, and Recharge &amp; Bills.

## Key Features
* Interactive date range filtering
* Transaction amount analysis
* Successful vs failed payment tracking
* Monthly trend analysis
* Failed payment reason analysis
* Service-wise transaction breakdown

## Tools & Technologies
* Power BI
* Power Query
* DAX
* MS Excel

## Dashboard Insights
* Identified monthly transaction trends
* Analyzed transaction success rate
* Compared service-wise revenue contribution
* Evaluated payment failure reasons
* Built interactive and user-friendly reports
